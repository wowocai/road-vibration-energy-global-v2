# 同步建设情景下的道路采能成本复核

本次没有获得Duarte原型的完整、可逐项匹配的批量生产报价。新计算为条件性成本阈值，不能把500或1000美元/对写成已证实市场价格。

## 结构证据

Duarte团队专利US10954926B2明确了盖板、曲柄滑块、齿条齿轮、单向轴承、轴/飞轮及换能器，并允许共享换能器变体；专利不能证明实验原型已采用共享结构或共享后维持同一产电量。来源：https://patents.google.com/patent/US10954926B2/en 。2020项目原型报告：https://conferences.sta.uwi.edu/iconetech2020/documents/A.Ferreira-PAVENERGYRESEARCHPROJECTRESULTSALREADYACHIEVEDANDNEWDEVELOPMENTS.pdf 。

## 数量与旧成本问题

20对/km是40个单模块，风能是20台完整风机。旧单价1959.90美元/对中，739.90美元是4类报价部件，1220美元是壳体、传动、电路和组装假设，占62.25%。不能视为完整匹配BOM，更不能用单件原型成本断言批量技术价格。

## 新情景

20年、5%折现率、原交通/负载/产电性能、共同10.24kWh储能和既有电网补足服务。同步施工增量100美元/对；道路与风机均每年按购置费1%维护，第10年更换25%设备价值，另100美元/对或台更换工时。以上均为情景参数，不是验证过的寿命或施工报价。保留更换50/100%、安装250/500美元/对及0.5/2%维护敏感性。
