# Release scope and version rules

1. The portable primary supply pipeline uses the unified complete road ledger and full road length; old positive-nightlight-weighted outputs are labelled comparison domains.
2. National VKT is refitted and country hold-out validation rerun; matrix/frequency integration is freshly evaluated. Trial device outputs anchor the mechanical-response scaling; no field measurement of ISOA–H generation is asserted.
3. Quick vehicle-energy output reaggregates included completed simulation records. Fresh ODE reruns require the separate explicit commands. Complete step-size/ensemble diagnostic records remain available.
4. Multi-energy output recomputes Savonius response and time-matching metrics from included minute/weather intermediates. Raw NASA JSON is supplied; a complete new raw-weather-to-minute reconstruction is not part of the default runner.
5. Lifecycle optimization uses the current recomputed Savonius minute series, common task-based maintenance, independently optimized battery capacity and grid purchases. Zero optimum battery capacity is an economic grid-backed result, not continuous off-grid autonomy.
6. Original full-resolution global SHP and VIIRS raster are not duplicated; processed record attributes and compact display geometry are supplied. Upstream source versions, projection, field rules and hash manifests are retained.
7. Historical rendering scripts and old-domain values in archive/ and module reference notes are provenance. The new portable plot is a current-data curve preview, not a claim that every journal composite and Word file has been replaced. Manuscript/SI/reviewer-response files and private reviewer identities are excluded from this public package.
8. The code is published at https://github.com/wowocai/road-vibration-energy-global-v2. The processed data are published at https://doi.org/10.5281/zenodo.24359475. Availability-link updates do not change numerical inputs, models or results.
