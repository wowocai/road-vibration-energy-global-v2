# ISO H：车速情景、能耗确认与零值假设核验

2026-11-17。本轮正式计算464个安装/未安装配对实现，完成432个，32个因姿态超域停止；原始JSON全部保留。这里的实现不是独立道路种子，统计区间先在同一种子内平均正反相位。

## 结论

**H采用2 km/h爬行参考情景，1–5 km/h用于速度对照。**该值是本文规定的数值参考，不是ISO给出的车速、通用道路安全限速或已由实车确认的适用车速。在当前车辆、路谱及装置参数下，H2的三档行程计算均得到稳定的正平均净轮端功；零新增功不受本批结果支持。50 km/h仍在姿态筛查中停止，不能将停止当作零损耗。

本轮没有更新正文、SI、回复Word及任何论文图片。H2与原A–H50同速比较并非同一组工况，之后若绘图必须标明H车速，并同步核对其他等级的模型及车速设置，不能只替换H柱而使读者认为只改变了粗糙度。

## 1. H级速度筛查

车辆2 t，20对采能装置/km，5 mm盖板上限；8个独立种子、正反相位对；每个实现预热/测量各200 m。原始道路为ISO H规定谱，0.01–3 cycles/m；本轮未降低粗糙度幅值以取得收敛。

| 车速(km/h) | 完成/计划 | 姿态超域数 | 完成样本平均零支撑时间(%) |
| --- | --- | --- | --- |
| 1.0 | 16/16 | 0 | 2.01 |
| 2.0 | 16/16 | 0 | 4.08 |
| 3.0 | 16/16 | 0 | 8.96 |
| 4.0 | 16/16 | 0 | 15.14 |
| 5.0 | 16/16 | 0 | 24.24 |
| 7.5 | 15/16 | 1 | 41.70 |
| 10.0 | 1/16 | 15 | 53.52 |

1–5 km/h的本批短程检查均完成；7.5 km/h已有失败，10 km/h多数失败。这里的“完成”只代表通过所设数值/姿态筛查，不等于安全性证明或实际通行能力验证。2 km/h参考下零支撑时间平均约4%，5 km/h约24%；本轮因此将2 km/h保持为预先声明的保守爬行参考，未为了使净功差为零而选择车速。不能把5 km/h称为普适最高安全车速。

另用8种子正反相位复查H50，16个实现全部超域停止。停止条件为任一车辆俯仰/侧倾绝对角达到90°，意味着该竖向模型已经不再适用，**不是预言实车必然翻覆**。提前终止的能量不按全计划距离外推，统计均值中不将这些实现填0。

## 2. H2参考能耗

| --- | --- | --- | --- | --- |
| 5 | 0.09733 | 0.05344 | [0.04622, 0.06065] | 0.04709 |

## 3. 为什么原有耗散能抵消一部分，却没有全抵消

采用相同道路、同速及同车参数的安装/未安装对照，完整账为：

Delta W_wheel = D_plate + Delta D_susp + Delta D_tyre + Delta D_stop + Delta E_terminal。

每个D非负，Delta D可有正负。5 mm、H2、32种子平均（J/车公里）：

| 能量项 | J/车公里 |
| --- | --- |
| 装置机械输入 | 97.32633 |
| 悬架耗散变化 | -35.56763 |
| 轮胎耗散变化 | -6.12567 |
| 止挡耗散变化 | -2.19784 |
| 末状态储能变化 | -0.00000 |
| 新增轮端机械功 | 53.43509 |

因此约97.33 J装置输入中，约43.89 J可由原有悬架、轮胎及止挡耗散的减少抵消，仍有约53.44 J新增轮端功。用户提出的“已有振动很强，装置可能替代原有损失”在该模型中体现为**部分抵消**，而不是全部抵消。

原模型未安装装置时，三类动态耗散合计约380.4 kJ/车公里。本轮新增轮端功分别约为该背景动态耗散的0.014%、0.040%、0.167%。这个相对量确实很小，但相对于所采集机械能仍不可忽略。上述百分比不是总油耗增量，也不包括气动、常规滚阻或动力系统效率换算。

新增两项诊断账：integral max(Delta P,0)dt、integral max(−Delta P,0)dt，均非负，二者之差等于净轮端功变化。它们是同时间安装/未安装功率差的正负分解，不是新增发动机功或制动能的独立实测量。

## 4. “零值”如何使用

| 情形 | 合理处理 |
| --- | --- |
| 计算未收敛或模型超域 | 保留状态说明，不赋予0点估计 |
| 收敛估计的区间包含0，但范围较宽 | 报告区间与无法确定正负，不能直接认定没有新增功 |
| 收敛且净变化落在事先说明的工程忽略范围 | 可报告“近似零”，注明忽略范围 |
| 明确规定所有装置机械输入均替代既有损失 | 可列为“零新增轮端功的理想回收情景Z0”，单独标为假设 |

本轮检查了工程等效范围：净轮端功为所采集机械能的±10%以内。方法是在独立种子配对均值上检验mean(Delta W+0.1D_plate)>0及mean(Delta W−0.1D_plate)<0的单侧95%界限。三档均未满足该“近似零”标准；10%为本轮明示的工程判断尺度，不是规范阈值。

Z0情景仍可作为明确的理想比较边界：设Delta W=0，则必须假定Delta D_susp+Delta D_tyre+Delta D_stop+Delta E=−D_plate。这个假定能满足能量账，但本轮车辆—盖板模型并未实现它。若列入论文，应写“在零新增机械能需求的理想回收假设下”，不能写成H实算结果，也不能由H50停止推导。

### 样本量

4/8/16/32种子的累积均值和区间见sample_stability.csv。16→32种子净功均值约变化7.7%–9.5%，主表明确保留约10%–14%的区间半宽，不声称采样误差已经消失。该残余不确定性不改变本批正增量结论，也不支持精确零值。

### 恢复代码及能量自检

上一轮修复包保存失败，本轮从已保存的adaptive.c及对话中记录的修复方程重建代码；无法恢复当时未成功保存的全部原始运行，因此本轮数据均重算，不伪称找回了上一轮776条记录。新增正负功率差账也会使自适应步长略有变化。

重新核对此前独立Radau代表算例（A50/H5，预热20 m、测量20 m、5 mm）的结果；与对话保留的Radau基准差均小于0.002 J。100个随机状态微分能量恒等式、各耗散非负、净功正负账恒等式，以及A50/H2零行程对照均通过。所有完成实现的配对能量闭合残差最大约0.0303 J/车公里。能量闭合本身不替代收敛检验。

## 6. 模型条件和来源

沿用上一轮有限转角竖向模型：2 t；20对/km；盖板k=77170.4861042 N/m、c/k=25 ms；5/10/25 mm盖板上限；轮胎阻尼400 N s/m；止挡80 mm启动、2 MN/m、耗散参数2 s/m；0.3048 m等效包络；左右轮迹相关幅值exp(−1×1.6×n)。车体偏航惯量按薄平面分布重建为俯仰与侧倾惯量之和。各几何、止挡及惯量参数仍是重建假设，不是Duarte实测结构。

- ISO官方说明：ISO 8608:2016，https://www.iso.org/standard/71202.html ，用于报告单/多轮迹竖向路谱。2 km/h由本研究设定，不从该标准推导安全车速。
- 接触力形式：Drake官方Modeling Compliant Contact，https://drake.mit.edu/doxygen_cxx/group__compliant__contact.html 。本代码自行实现力律，不是Drake仿真验证。
- 止挡及轮胎细节：Soong等(2017)，https://doi.org/10.1371/journal.pone.0179485 。支持加入模型细节，不提供本装置的特定参数。
- 双轮迹指数相关参考：Wang等(2021)，https://doi.org/10.1177/16878140211007323 ，式7的rho=1参考；Bogsjö(2008)，https://doi.org/10.1080/00423110802018289 ，及Lamb & Rouillard(2021)，https://doi.org/10.1016/j.probengmech.2021.103168 。本轮使用相关/非相关谱分量保持单侧期望PSD，未声称复现非平稳实测道路。
- 轮胎阻尼范围重建：Türkay & Akçay(2008)，https://doi.org/10.1016/j.jsv.2007.09.014 ，出版商可检索片段给出0.03–0.10阻尼比；400 N s/m按既有车轮质量/刚度折算约0.053，非原型辨识值。
- 包络尺度：Arizona DOT SPR-340，https://apps.azdot.gov/ADOTLibrary/publications/project_reports/PDF/AZ340.pdf ，12英寸乘用车近似。不是特定轮胎的实测接地长度。
- 盖板研究行程范围沿用Khan & Al-Qadi(2026)摘要，https://doi.org/10.1080/10298436.2026.2748451 ，非Duarte原型行程验证。
- 原试验239.4 J/对机械与144.8 J/对电量来自已有试验转录；本轮未重读原装置全文，也不将假定效率下的H2电量称为实测产电。

## 7. 文件与使用

主代码model/model.c、model/run.py；构建命令：

```bash
cc -O3 -shared -fPIC model/model.c -o model/model.so -lm
```

依赖Python、numpy、scipy、pandas。model/study.py依次提供screen、precision、confirm、ensemble；model/independent_roads.py和highspeed_recheck.py为额外核验；model/verify.py完成恒等式及前次Radau基准检查；analyze.py生成统计表。reconstruct.py可从previous/adaptive_validation/adaptive.c重建模型源。重新改变模型/参数后，缓存以源代码和参数哈希区分，不混用历史运行。

- runs/：逐实现结果，含模型哈希、参数、状态和起止位置。
- out/raw_cases.csv：全部原始运行。非completed状态的能量为中途诊断，不得按全程外推。
- out/seed_pairs.csv：同种子内正反相位平均，区间按独立种子计算。
- out/summary.csv：各条件均值、区间、有效数、非负负担派生量、10%零近似筛查。
- out/sample_stability.csv：4/8/16/32种子检查。
- verification.json：独立积分器历史基准、微分能量恒等式和零行程对照。

这些数据属于规定结构的数值情景。H2结果不直接替换Duarte在2 t、50 km/h下144.8 J/对的实测锚点；若以后更新供电地图，须统一装置结构、车速、单次产电和部署口径。图i若同时保留其他等级50 km/h和H2，应改为明确的路况—车速联合情景，不能仍称纯粗糙度同速比较。
