## 1. 计算定义与保持一致的边界

同一随机路谱同时积分安装装置与未安装装置车辆，直接累计轮端功差，并核对：

ΔW_wheel = D_plate + (D_susp,with − D_susp,without) + (ΔE_with − ΔE_without)。

其中末项保留测量起止状态的储能差，不通过强制归零改变结果。负载侧电量=新计算的盖板机械耗散×(144.8/239.4)×0.8。60.4845%来自前一证据包转录的实测机械/电量比；将该比值用于受限行程等效模型以及80%下游保留率均是既有情景假定。没有把基准悬架耗散全部计入回收电量，也没有把装置机械输入直接当作额外牵引功。

主图i的车辆为2 t、50 km/h，每公里20对装置，盖板上限5/10/25 mm，单车实际压过装置；未再扣50%交互因子。等效盖板k=77170.4861042 N/m、c/k=25 ms；1.1 m正弦平方接触权重及车身参数沿用上一重建。刚度原先按无限行程平路机械输入239.4 J标定，施加新上限后**未重新调参恢复239.4 J**。这不是Duarte原型精确结构的复现。

## 2. 轮胎脱离/再接触与积分精度

- 法向接触采用单边弹性关系F=k_t max(δ,0)，δ=0为脱离/再接触事件。事件两侧连续积分，定位根后重新计算接触状态；不补入未经证实的刚体冲量或恢复系数。
- 加入两块板上限事件。达到上限且加载继续增大时，限位支撑承担余力，板速度为零，不产生采能功。记录极小数值越界并控制能量闭合。
- 使用RK4步长加倍误差估计的自适应积分。位置、速度及每步功增量共同控制误差，功增量控制不因累计量变大而放宽。
- 固定连续路谱后改变积分器。路面采用周期三次Hermite插值，导数由傅里叶谱生成，避免把积分精度变化与路谱重采样混为一项。
- H的8个独立种子、正反相位对、三种盖板行程分别测试相对容差2×10⁻⁶、4×10⁻⁷、8×10⁻⁸；最大步长分别2.5、1.25、0.625 ms。A、G另有代表性5 mm精度试算，原固定步长包保留A–G检查。

H的新增轮端功仍未通过精度独立性检验。以5 mm、相同8个种子、预热/测量各1 km为例，三档精度的均值为−27.543、−35.449、−32.419 kJ/车公里；机械耗散分别约488.2、493.2、498.8 J/车公里。机械耗散变化较小，但不能据此认定差值能耗已收敛。单独的未安装装置轨迹也有敏感性，不能把问题全部归于盖板限位。

## 3. 时长与路谱样本数

1. 预热4 km后，测量1、4、8 km，8个独立路谱种子及正反相位对。这里沿1 km周期路谱重复行驶，检查时间平均，**不把重复周期算作新增独立路谱**。
2. 主H集合扩大至64个独立种子3101–3164，每个种子正反相位配对，预热4 km、测量4 km，三种行程。每种行程的样本数是64，不是128；两条正反相位实现先在种子内取均值。
3. 另生成16个独立8 km空间路谱，预热1 km、测量4 km，检查结论是否只是重复1 km路面的结果。测量段与预热段不重叠。
4. 全部情景空间频带0.01–3 cycles/m，ISO A参考PSD为16×10⁻⁶ m³（0.1 cycles/m），谱斜率−2；相邻等级位移幅值加倍。未为了取得较平滑H结果降低PSD或悄悄改变频带。

平均新增轮端功仍随时长、种子数和积分设置变化。64种子下的采样区间均跨零；这表示当前试算不能可靠确定H平均额外轮端功的符号和大小，并不表示已证明零代价或能耗减少。主集合最初排队128种子；在64种子全部完成且模型适用性检查明确失败后结束继续扩样。队列中另完成的7个种子—行程任务保留于原始数据，不纳入预先统一的64种子主汇总。

## 4. 接触包络、悬架限位和车速检查

接触包络：采用0.3048 m移动平均滤波的等效轮胎包络，滤波后同步更新路面高度和速度输入。该方法和12英寸尺度来自Arizona DOT技术报告中的乘用车包络近似，不是该原型轮胎接地长度实测值。它仅是空间滤波近似，不是完整椭圆凸轮/三维轮胎模型。

悬架止挡：在相对行程达到60、80或100 mm后启用附加单边弹簧，止挡刚度取主悬架刚度的100、1000倍。止挡能量纳入总储能，激活/退出加入事件定位；止挡本身采用弹性可压缩表示，阈值不等于不可穿透硬上限。具体阈值和刚度是明确列示的工程敏感性假设，并非从论文测得的Duarte参数。Soong等支持考虑止挡的建模必要性，不为这些取值提供原型标定。

速度：固定H路谱、车辆及5 mm盖板，检验50、20、10 km/h，每组8个独立种子及正反相位对。

结果：50 km/h原始点接触模型中，H的样本峰值悬架相对行程平均约1.388 m，轮胎平均脱离时间比例约77.1%；引入包络后仍约1.358 m。80 mm启动、1000倍刚度的止挡把平均峰值行程压至约0.122 m，但同时出现约96.4%的脱离时间，样本峰值轮胎力平均约539 kN，不能把这种“位移较小”称为可行车辆工况。组合包络与止挡也未解决能耗差值问题。60–100 mm止挡及两档刚度的完整结果列于validation_summary.csv。

降至20、10 km/h时，脱离时间比例分别约62.0%、40.0%，平均样本峰值悬架相对行程仍约0.887、0.654 m。降低车速有所改善，但本轮未找到可直接认定为正常通行的H基准；不能仅把主图H换成低车速后声称同速A–H对比成立。在当前频带及PSD下，种子3101的H路面单轮迹高度RMS约0.524 m、坡度RMS约0.556；必须连同频带说明，不能当作全部真实H路面的通用几何。

结论：H在当前路谱—车辆—50 km/h组合下同时存在数值敏感性和车辆模型适用性问题。继续盲目缩步长或加样本不能替代接触几何、非线性悬架及可通行速度的物理标定。本轮完成这些问题的定量诊断，**没有将H修复成已验证、已收敛的正常运行点**。

## 5. 图、SI和审稿回复如何使用

- 图i与3×3总图现在均显示H三档行程的条件均值、采样区间及电量，不再留空。H使用浅色底区和星号，说明其数值收敛尚未建立。不能删掉该说明而保留负柱。
- a–h原有供需与阵列情景未被本次盖板模型替换。a–h使用既有实测锚定/规定阵列输入，i为新增行程受限等效装置对照；两者不是相同结构的同步试验。不能用i的车辆能耗去抵扣a–h的电量后得到“净能源收益”。若要完成这种抵扣，必须先统一装置几何、行程和产电输入，再重算相关供需结果。
- SI可安排：模型方程与能量项；参数/来源表；事件积分器；时间、容差、独立种子及8 km路谱检查；接触/止挡/车速敏感性；H条件数值表和验证图。
- 对R3.10应逐项指向新增结果段、图i及SI上述表图，说明已计算安装/未安装配对轮端功。现阶段不能回复“所有A–H车辆附加能耗均已收敛”。该条要求的跨全部情景可靠能耗结论仍待物理模型标定，不能用本报告将其标为完全闭合。

## 7. 复现与数据字典

依赖Python、numpy、pandas、scipy、matplotlib和C编译器。基础模型运行run.py；批计算sweep.py的duration/ensemble，reference.py；细节模型生成make_variants.py并运行diagnostics.py的precision/details/nonperiodic及stop_sensitivity.py；汇总analyze.py，验证图validation_plot.py。独立种子取值见脚本与逐算例CSV。修改模型后应移走旧runs/diagnostic_runs缓存，禁止用旧结果拼接新参数。

- adaptive.c：配对44状态、事件定位、自适应误差控制。variant.c：加止挡及行程诊断的版本。
- all_cases.csv：每个正/反相位实际运行，能量原始J及每公里归一化列；每行同时包含安装与对照车辆结果。参考模型采用同一自适应时间步。
- independent_seed_means.csv：先在种子内平均正反相位，防止把相关实现当作独立样本。
- A_H_energy_summary.csv：主图i源数据。A–G为16独立种子、预热/测量各1 km；H为64独立种子、预热/测量各4 km。时长检验在另表列出，不能隐去不同计算长度。
- validation_summary.csv：三档容差、不同长度、包络、止挡和车速等全部汇总；H_sample_convergence.csv：8/16/32/64种子累积均值与区间。
- events字段是定位操作次数，含重试，不可解读为独立物理撞击次数。
- off_fraction为四轮无接触时间的平均比例，不是车辆整体完全腾空比例。
- peak_suspension_travel_m为各实现四悬架绝对相对行程的最大值；汇总为这些样本峰值的均值，不是平均悬架行程。
- 轮端功差保留有符号估计，不裁负、不按电量反推、不用能量闭合替代收敛检验。

本包原始逐算例CSV共1598行，包含14行主64种子以外的已完成辅助运行；最大配对能量闭合残差约0.682 J/车公里。该残差小不代表H轨迹和均值收敛。

额外自检：A、H的零盖板行程对照均得到零板功和零轮端功差；全部主字段有限、板功非负、板行程不越界、主汇总样本数正确。该自检核对记账一致性，不代表H物理有效。验证图需要Times New Roman；同包总图源文件保留原字体安装包及提取脚本，亦可使用已安装同名字体。
