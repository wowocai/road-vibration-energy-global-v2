# 图3供需范围与机械能口径核对

原需求虚线图把全部 6,906,689 km 的道路机械输入与 3,387,073 正夜光加权公里的需求相比较。新版统一在候选加权范围内统计供给与需求。该变更只调整图3总量的统计范围，不更改原逐路段供需匹配算法或其24.65%的基准结果。

ISO A：试验参照方案机械输入从全路网8.99154 TWh，调整为同一候选道路范围内6.92603 TWh。机械输入按144.8/239.4的试验效率和80%下游保留率折算，候选范围内的负载侧电量为3.35134 TWh。逐段需求封顶后的当地照明电量约2.9892 TWh，基准照明需求12.12649 TWh，年需求匹配率约24.65%。全路网电量4.35079 TWh不是候选道路的供电总量。

每公里20对原型，名义间距50m，一对为左右轮迹两模块；每公里40个全车加载排，名义间距25m。两组沿用2吨、50km/h，并假定50%通行车辆有效触发。对全部候选加权道路均匀布设，等效为约6774万对原型或1.355亿加载排。这是规模化部署情景，不是现存装置数量。路面等级A–H也是统一情景，不是路网实际等级占比。

机械能响应是16个独立随机相位组、每组128个位置及其反相配对的平均，再逐路段乘2015年预测AADT。车辆质量和速度是规定工况，不是全球实际车队分布的平均。

载荷–行程参照方案的A级输入98.1 J/排来自2000×9.81×0.005，40排每公里。B–H借用试验参照方案的相对响应曲线。这是一项共享响应假设，并非对第二种结构的独立试验验证。

需求与采能装置并非一对一：0.120 W/km为每公里一台雷达电子部件；1.805及27.164 W/km为规定功率预算；408.702 W/km相当于每公里20盏Fingal基准灯的年平均用电。候选加权道路范围内每公里20对原型在ISO A下，平均负载侧产能989.45 kWh/(km·年)；每公里20盏灯的需求为3580.23 kWh/(km·年)。供给均值不表示每段道路都能达到该水平。

虚线为对应电量需求除以共同参考机电效率60.4845%及下游保留率80%得到的等效机械输入。此效率用于第二组时仅是共同折算参照。虚线能比较总量尺度，不能表达逐段自给、连续运行或夜间自主供电。D–H还依赖固定车速下的间歇接触和装置响应假设。
