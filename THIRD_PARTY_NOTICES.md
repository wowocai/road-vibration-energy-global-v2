# Rights and third-party materials

The author must choose a software license for original code and a compatible data license before public release. This package does not grant rights on the author's behalf. Existing source/data-provider terms continue to apply; citation alone is not redistribution permission.

The road attributes and simplified geometry derive from ETH/GRIP; weather from NASA POWER; satellite-derived attributes from VIIRS products; trial data from the cited papers; prices from named suppliers. Check provider terms when assigning Zenodo licenses. ISO standard text is not included. Fonts, installers, proprietary runtimes, credentials and private manuscripts/reviewer documents are excluded. Quote snapshots record research inputs, not current offers.
