# 按维护工作量拆分和分别配置储能的重算

运行 `python optimize.py`，需要 Python numpy、pandas 及 g++。脚本从原始 minute_inputs.npz 读取全年525600个分钟的出力与负载，编译 dispatch.cpp，产生 out 内CSV和 assumptions.json。二进制输入与可执行程序可重新生成。

当前主结果是既有电网补足同一需求下的20年最低成本，光伏10.24 kWh、微风0、振动0。不配置电池不等于无储能自治：微风/振动依赖电网填补缺口。

维护不再按设备价格的1%计算。共同巡检为两次/年、每次一人时/km、40美元/人时，合计80美元/年。技术专属作业按光伏两次各3分钟/组件、风机一次6分钟/台、道路装置一次6分钟/对配置，均2人时/年，加20美元耗材，合计100美元/年。以上次数、工时、耗材及工资为相同工作量基准的工程假设，不是已测定的服务周期或厂家报价。DOE资料支持按检查/清洁/纠正维修拆分的方法，不支持这些特定工时。另扫描专属作业1/2/4人时。道路封道和异常故障未取得报价，需专项加项；主体25%第10年更换已单列，不在日常维护中重复计入。

储能容量以5.12 kWh/模块，检验0–16模块，购置1097.99美元/模块，加620美元集成初始费用。可用80%、往返效率85%、充放电各5 kW，无电网充电。储能巡检另计0.25人时/年即10美元/年，不再用储能价值1%重复计费。电池更换间隔为10年日历假设和4000/年等效满循环数中的较小值，循环以电池内部放出电量除以标称容量计。4000次100%DoD的厂家指标仅作吞吐量寿命筛查，不是雨流循环/温度/衰减模型。名义容量在各运行年固定，未模拟逐年衰减。日历5/10/15年、电价0.08/0.16/0.32美元/kWh、电池价0.5/1/2倍均扫描。容量0.25kWh步长及线性单价扫描是连续价格敏感性，不表示找到了相应小电池商品。

以同一年的输入循环至年初末SOC一致，避免免费初始能量。每一容量检查供需、电池和总电量守恒。每公里负载年需求3581.279266kWh。供能不足购电；不售电、不计碳收入，现有接网视为共同条件。光伏发电保持原9247.76kWh、微风0.0111kWh、道路796.83kWh。采能装置数量和非储能价格均固定，不重新优化发电装置规模。道路仍用低价齿条/轴承候选及0.5折减系数，机械兼容性未验证；不能将结果表述为已建成装置的实际采购与运行费用。

## 结果

| 项目 | 光伏 | 微风能 | 振动采能 |
|---|---:|---:|---:|
| 最低成本模块容量 kWh/km |10.24|0|0|
| 共同巡检 美元/km/年 |80|80|80|
| 专属维护 美元/km/年 |100|100|100|
| 年补购电 kWh/km |1080.71|3581.27|3252.68|
| 20年成本现值 美元/km |22482.16|34465.58|34122.80|

保留10.24kWh相同容量、仅改变维护算法时：光伏22482.16、风38877.10、振动37740.75美元/km。储能优化进一步降低后两者约4411.53与3617.95美元/km。振动选择5.12kWh可将本地可用电由328.60增至726.60kWh/年，但20年成本由34122.80增至35968.69美元/km，因此当前0.16美元/kWh下不划算。该配置在较高电价或较便宜电池情景可能改变，见 storage_cost_sensitivity.csv。

在相同10.24kWh容量下，光伏264.81等效满循环/年，振动42.16次/年，微风约0.000021次/年。实际循环量不同；在本基准4000EFC、10年日历筛查中均由日历假设决定更换，未人为给出不同更换寿命。

## 文件

- optimized_cost_breakdown.csv：分别优化后的逐项成本、购电、SOC、吞吐量、EFC及寿命。
- fixed_capacity_new_maintenance.csv：同容量下的新维护算法对照。
- module_capacity_sweep.csv：可采购5.12kWh模块网格的全部结果。
- relaxed_optima.csv / relaxed_capacity_sweep.csv：线性储能单价与细容量敏感性。
- storage_cost_sensitivity.csv：电价、日历寿命及电池价格联合敏感性。
- maintenance_sensitivity.csv：维护工时敏感性。
- assumptions.json：全部假设、来源及计算边界。
